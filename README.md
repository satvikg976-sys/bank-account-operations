# Bank Account Operations

A simple Java-based Bank Account Operations application developed using Maven and JUnit.

## Project Overview

This project demonstrates basic banking operations such as:

- Deposit money
- Withdraw money
- Transfer money
- Check account balance

## Technologies Used

- Java
- Maven
- JUnit 5
- Git
- GitHub
- GitHub Actions
